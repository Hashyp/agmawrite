## [0.1.0]

Initial release.

### Added

- Distraction-free Markdown writing surface: dim syntax, bright prose, iA
  Writer Mono S bundled (SIL OFL).
- Rendered preview on `Ctrl + P`, navigable with vim motions and counts.
- Caret mirroring between write and preview surfaces.
- Open (`Ctrl + O`) and save (`Ctrl + S`) via native file dialogs.
- Find in preview (`Ctrl + F` or `/`).
- Comments: `c` anchors a note to the caret or a visual selection; threads,
  edit history, and resolve/delete in the sidebar (`Ctrl + B`, `Ctrl + N`).
- Searchable shortcut reference (`Ctrl + ?`).
- Colors follow the active Omarchy theme and repaint live on theme change.
